# ZappIA

Zappy Artificial Intelligence.

## Build

```bash
# 0. Upgrade python (optional)
pip install --upgrade pip

# 1. Create a new env
python -m venv .venv
source .venv/bin/activate      # Linux/Mac
# .venv\Scripts\activate       # Windows

# Install project
pip install -e .

# Verify installed
pip list
```
